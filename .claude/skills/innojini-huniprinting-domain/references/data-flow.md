## Paper Name Matching Rules

### 표기법 차이 패턴

| 패턴 | 상품마스터 예시 | 인쇄가격표 예시 | 매칭 규칙 |
|------|---------------|----------------|----------|
| 약어 vs 풀네임 | 랑데뷰 WH 240g | 랑데뷰 울트라화이트 240g | 약어 테이블 참조 |
| 절수 표기 | 몽블랑 130g (T3절) | 몽블랑 130g (3절) | T 제거 후 비교 |
| 특수문자 | 랑데뷰 WH 240g ★ | 랑데뷰 울트라화이트 240g | ★ 제거 후 비교 |
| 공백 차이 | 아트지100g | 아트지 100g | 공백 정규화 |

### 약어 매핑 테이블

```python
PAPER_ABBREVIATIONS = {
    "WH": "울트라화이트",
    "T3절": "3절",
    "T4절": "4절",
    # 추가 약어...
}
```

### 매칭 알고리즘

```python
def normalize_paper_name(name):
    """용지명 정규화"""
    if not name:
        return ""
    
    # 1. 특수 마커 제거
    name = name.replace("★", "").replace("●", "")
    
    # 2. 약어 치환
    for abbr, full in PAPER_ABBREVIATIONS.items():
        name = name.replace(abbr, full)
    
    # 3. 공백 정규화
    name = " ".join(name.split())
    
    # 4. 소문자 변환 (비교용)
    return name.strip().lower()

def match_paper_name(master_name, price_name):
    """용지명 매칭"""
    return normalize_paper_name(master_name) == normalize_paper_name(price_name)
```

## Known Discrepancy Patterns

### 불일치 유형 1: 약어 차이

```
마스터: 랑데뷰 WH 240g ★
가격표: 랑데뷰 울트라화이트 240g
→ 해결: 약어 테이블 적용
```

### 불일치 유형 2: 절수 표기

```
마스터: 몽블랑 130g (T3절)
가격표: 몽블랑 130g (3절)
→ 해결: "T" 제거
```

### 불일치 유형 3: 신규 용지

```
마스터에만: 그문드컬러매트 블루300
가격표에만: 뉴크라프트
→ 해결: 수동 동기화 필요
```

### 불일치 유형 4: 용지 코드 vs 이름

```
마스터: 용지명으로 참조
가격표: 용지코드(240901006) 보유
→ 권장: 코드 기반 참조로 전환
```

## Validation Queries

### 용지 정합성 검증

```python
def validate_paper_integrity(master_papers, price_papers):
    """용지 참조 무결성 검증"""
    
    # 정규화된 이름으로 비교
    master_normalized = {normalize_paper_name(p) for p in master_papers}
    price_normalized = {normalize_paper_name(p) for p in price_papers}
    
    results = {
        "common": master_normalized & price_normalized,
        "master_only": master_normalized - price_normalized,
        "price_only": price_normalized - master_normalized,
    }
    
    return results
```

### 가격 계산 검증

```python
def validate_price_calculation(product, qty, paper_price, print_price, finishing_price):
    """가격 계산 검증"""
    
    pansu = product['pansu']
    paper_cost = paper_price / pansu
    
    unit_price = paper_cost + print_price + finishing_price
    
    discount_rate = get_discount_rate(qty)
    final_price = unit_price * (1 - discount_rate) * qty
    
    return final_price
```
