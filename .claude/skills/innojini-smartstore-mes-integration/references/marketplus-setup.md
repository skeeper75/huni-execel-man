# 마켓플러스 설정 가이드

## 사전 준비

### 1. Cafe24 쇼핑몰
- Cafe24 쇼핑몰 개설 완료
- 관리자 계정 접근 권한

### 2. 스마트스토어
- 네이버 스마트스토어 개설 완료
- 판매자 센터 접근 권한

### 3. API 설정
- Cafe24 개발자 센터 앱 등록
- 네이버 커머스 API 가입

## 마켓플러스 연동 설정

### Step 1: 마켓계정 연동

1. Cafe24 관리자 → 마켓플러스 → 마켓계정 관리
2. "네이버 스마트스토어" 선택
3. 스마트스토어 로그인 인증 진행

### Step 2: API 대행사 설정 (중요!)

⚠️ **필수 설정**: 스마트스토어 API 대행사를 **Cafe24를 첫 번째**로 지정

1. 네이버 판매자센터 로그인
2. 판매자정보 → API 설정
3. API 대행사 관리
4. **Cafe24를 1순위로 설정**

```
[API 대행사 설정 예시]
1. Cafe24 (필수 - 첫 번째)
2. 기타 연동 서비스 (있는 경우)
```

**주의:** Cafe24가 첫 번째가 아니면 주문 수집이 정상 작동하지 않음

### Step 3: 상품 연동

1. 마켓플러스 → 상품관리 → 가져오기
2. 스마트스토어 상품 선택
3. Cafe24 상품과 매칭

또는

1. 마켓플러스 → 상품관리 → 보내기
2. Cafe24 상품 선택
3. 스마트스토어로 등록

### Step 4: 주문 연동 설정

1. 마켓플러스 → 환경설정 → 기본설정
2. 주문 자동 수집: ON
3. 수집 주기: 실시간 (권장) 또는 5분

```
[주문 처리 흐름]
스마트스토어 주문 발생
    ↓
마켓플러스 자동 수집 (연동 시점부터)
    ↓
Cafe24 주문으로 동기화
    ↓
MES에서 Cafe24 API로 조회
```

### Step 5: 배송 설정

1. 마켓플러스 → 환경설정 → 배송설정
2. 기본 택배사 설정
3. 송장 자동 전송: ON

## 주의사항

### 연동 시점
- 마켓플러스 연동 **이전** 주문은 수집되지 않음
- 연동 시점부터의 주문만 동기화됨

### Rate Limit
- 네이버 커머스 API: 초당 2회
- Cafe24 Admin API: Leaky Bucket (초당 2회 감소)
- 동시 요청 시 429 에러 주의

### 상품 매칭
- 옵션 구조가 다르면 별도 매핑 필요
- SKU 기반 매칭 권장

### 재고 동기화
- 기본: 마켓플러스가 Cafe24 기준으로 동기화
- MES 연동 시: MES → Cafe24 → 마켓플러스 → 스마트스토어

## 문제 해결

### 주문 수집 안됨
1. API 대행사 순서 확인 (Cafe24 = 1순위)
2. 네이버 API 연동 상태 확인
3. Cafe24 토큰 만료 여부 확인

### 송장 전송 안됨
1. 택배사 코드 확인
2. 송장번호 형식 확인
3. API 에러 로그 확인

### 재고 불일치
1. 동기화 설정 확인
2. 수동 동기화 실행
3. 상품 매핑 상태 확인
