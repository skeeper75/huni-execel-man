## 3. 문제점 분석

### 3.1 데이터 구조 문제

| 문제 유형 | 상세 내용 | 영향도 | 예시 |
|----------|----------|:------:|------|
| 비표준 헤더 위치 | 시트마다 헤더 행 위치 상이 | 🔴 높음 | 1행, 2행, 4행 혼재 |
| 코드 체계 불일치 | 영문/한글 코드 혼용 | 🔴 높음 | DigitalPrint vs 디지털 |
| 중복 시트 존재 | 원본/수정본 병존 | 🟡 중간 | 디지털출력비 2개 |
| 셀 내 주석 혼재 | 데이터와 메모 미분리 | 🟡 중간 | 빨간색 안내문구 |
| 빈 행/열 존재 | 테이블 경계 불명확 | 🟡 중간 | 구분용 빈 행 |

### 3.2 유지관리 문제

| 문제 유형 | 상세 내용 | 리스크 |
|----------|----------|--------|
| 가격 변경 시 다중 수정 | 동일 상품 여러 시트 분산 | 누락/불일치 |
| 이력 관리 불가 | 변경 히스토리 없음 | 추적 불가 |
| 검증 로직 부재 | 입력값 검증 없음 | 오류 가격 |
| 권한 관리 없음 | 누구나 수정 가능 | 무단 변경 |

### 3.3 자동화 장애 요인

```
❌ 현재 상태에서 자동화가 어려운 이유

1. 데이터 위치 예측 불가
2.    - 시트마다 시작 위치가 다름
3.    - VLOOKUP 범위 설정 어려움
4. 통합 조회 불가능
5.    - 상품코드 체계가 없음
6.    - 여러 시트 연결 불가
7. 가격 계산 로직 파악 어려움
8.    - 수량 구간 기준 불명확
9.    - 할인율 적용 기준 없음
10. 데이터 타입 혼재
11.   - 숫자/텍스트 혼합
12.    - 수식/값 혼합
13. ```

## 4. 표준화 방안

### 4.1 데이터 정규화 원칙

#### 원칙 1: 단일 원천 (Single Source of Truth)
- 모든 기준 정보는 마스터 시트에서 관리
- - 가격표는 마스터 데이터 참조
#### 원칙 2: 코드 표준화
```
상품코드 체계: [대분류]_[중분류]_[상품명]_[옵션]

예시:
- DIG_PAPER_WHITE_100G   → 디지털_용지_백색모조지_100g
- - POST_BIND_SADDLE_001   → 후가공_제본_중철_001
- - GOODS_MUG_CERAMIC_11OZ → 굿즈_머그컵_도자기_11온스
- ```
#### 원칙 3: 테이블 구조 통일
- 모든 시트 1행: 헤더
- - 2행부터: 데이터
- - 빈 행/열 금지
### 4.2 권장 테이블 구조

#### 4.2.1 상품 마스터 테이블

| 컬럼명 | 데이터타입 | 필수 | 설명 |

| product_code | TEXT | ✓ | 상품 고유 코드 |
| category_l | TEXT | ✓ | 대분류 |
| category_m | TEXT | ✓ | 중분류 |
| product_name | TEXT | ✓ | 상품명 |
| unit | TEXT | ✓ | 기본 단위 |
| min_order | NUMBER | ✓ | 최소 주문 수량 |
| status | TEXT | ✓ | 상태 (활성/비활성) |
| created_date | DATE | ✓ | 등록일 |
| updated_date | DATE | ✓ | 수정일 |

#### 4.2.2 옵션 마스터 테이블

| 컬럼명 | 데이터타입 | 필수 | 설명 |

│              ┌───────▼───────┐                                  │

│              └───────────────┘                                  │

### 5.2 Agent 1: Master Data Agent (기준정보 관리)

#### 역할
기준 정보(상품, 옵션, 코드)의 등록, 수정, 삭제 관리

#### 스킬 목록

| 스킬명 | 기능 | 입력 | 출력 |
|--------|------|------|------|
| create_product | 신규 상품 등록 | 상품 정보 | 상품 코드 |
| update_product | 상품 정보 수정 | 코드, 변경내용 | 성공/실패 |
| search_product | 상품 검색 | 검색 조건 | 상품 목록 |
| manage_option | 옵션 관리 | 옵션 정보 | 성공/실패 |
| generate_code | 코드 자동 생성 | 상품 정보 | 표준 코드 |

#### 구현 예시 (Apps Script)

```javascript
/**
 * 상품 코드 자동 생성
 *  * @param {string} category_l 대분류
 *  * @param {string} category_m 중분류  
 *  * @param {string} product_name 상품명
 *  * @return {string} 생성된 상품 코드
 *  */
 * function generateProductCode(category_l, category_m, product_name) {
 *   const categoryMap = {
 *     '디지털인쇄': 'DIG',
 *     '후가공': 'POST',
 *     '제본': 'BIND',
 *     '스티커': 'STK',
 *     '굿즈': 'GOODS'
 *   };
 *   
 *   const prefix = categoryMap[category_l] || 'ETC';
 *   const seq = getNextSequence(prefix);
 *   
 *   return `${prefix}_${category_m.substring(0,3).toUpperCase()}_${seq}`;
 * }
 * ```
### 5.3 Agent 2: Price Lookup Agent (가격 조회)

#### 역할
상품별 가격 조회, 견적서 생성, 가격 비교 분석

#### 스킬 목록

| 스킬명 | 기능 | 입력 | 출력 |
|--------|------|------|------|
| get_unit_price | 단가 조회 | 상품, 옵션, 수량 | 단가 |
| calculate_total | 총액 계산 | 상품 목록 | 총액 |
| create_quote | 견적서 생성 | 고객, 상품목록 | 견적서 |
| compare_prices | 가격 비교 | 상품, 수량범위 | 비교표 |
| recommend_qty | 최적 수량 추천 | 상품, 예산 | 추천 수량 |

#### 구현 예시 (Apps Script)

```javascript
/**
 * 단가 조회
 *  * @param {string} productCode 상품 코드
 *  * @param {string} optionSet 옵션 조합
 *  * @param {number} quantity 수량
 *  * @return {number} 단가
 *  */
 * function getUnitPrice(productCode, optionSet, quantity) {
 *   const priceSheet = SpreadsheetApp.getActiveSpreadsheet()
 *     .getSheetByName('P_가격마스터');
 *   const data = priceSheet.getDataRange().getValues();
 *   
 *   for (let i = 1; i < data.length; i++) {
 *     if (data[i][0] === productCode && 
 *         data[i][1] === optionSet &&
 *         data[i][2] <= quantity && 
 *         data[i][3] >= quantity) {
 *       return data[i][4]; // 단가 반환
 *     }
 *   }
 *   return null; // 가격 없음
 * }
 * ```

| 데이터 이관 | 개발 | 정규화 데이터 | 검증 완료 |

### 6.2 Phase 2: 조회 시스템 구축 (1~2주)

| 작업 | 담당 | 산출물 | 완료 기준 |

## 7. 즉시 적용 가능한 개선사항

### 7.1 Google Sheets 기본 기능 활용

#### 7.1.1 데이터 유효성 검사

```
메뉴: 데이터 → 데이터 유효성 검사

적용 예시:
- 상품분류: 드롭다운 목록
- - 수량: 정수, 1 이상
- - 가격: 정수, 0 이상
- - 날짜: 유효한 날짜
- ```
#### 7.1.2 조건부 서식

```
적용 예시:
- 빈 셀: 빨간색 배경
- - 중복 값: 노란색 배경
- - 가격 이상치: 주황색 배경
- ```
#### 7.1.3 이름 정의 (Named Range)

```
이름 정의 예시:
- 상품목록: M_상품마스터!$A$2:$A$500
- - 옵션목록: M_옵션마스터!$B$2:$B$100
- - 가격테이블: P_가격마스터!$A$1:$H$1000
- ```
### 7.2 핵심 수식 템플릿

#### 가격 조회 (INDEX-MATCH)

```
=INDEX(가격테이블, 
  MATCH(1, 
      (상품코드=A2)*(옵션=B2)*(수량>=C2)*(수량<=D2), 
          0), 
            5)
            ```
#### 상품명 조회 (VLOOKUP)

```
=VLOOKUP(A2, 상품목록, 4, FALSE)
```

#### 총액 계산

```
=SUMPRODUCT(수량범위, 단가범위)
```
