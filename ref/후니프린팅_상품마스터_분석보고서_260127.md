## 2. 발견된 문제점

### 2.1 데이터 일관성 부재

**문제**: 시트마다 컬럼명과 순서가 다름

| 항목 | 스티커 | 디지털인쇄 | 포토북 |
|------|--------|------------|--------|
| 식별자 컬럼 | code | ID | ID |
| MES 코드 | MES ITEM_CD | MES ITEM_CD | MES ITEM_CD (SET) |
| 옵션 표시 | 사이즈옵션 | 사이즈옵션 | 사이즈옵션 |

**영향**: 
- 통합 조회 어려움
- - 자동화 스크립트 작성 복잡
- - 신규 직원 학습 비용 증가
### 2.2 코드 체계 혼재

**현황**:
- MES ITEM_CD 형식: 002-0001, 001-0001 등 시트별 별도 관리
- - code/ID 중복 사용으로 내부 코드 관리 체계 불명확
### 2.3 중복 데이터 위험

**문제점**:
- 동일 상품이 여러 시트에 분산 가능
- - 사이즈 옵션이 별도 행으로 반복 입력
### 2.4 데이터 유효성 검증 부재

**현황**:
- 드롭다운 또는 데이터 유효성 검사 없음
- - 자유 텍스트 입력으로 오타 위험 높음
**명명 불일치 예시**:
- "반칼 자유형" vs "반칼(자유형)"
- - "날장 자유형" vs "날장자유형"
### 2.5 가격 정보 관리 문제

**현황**:
- 연단가 직접 입력으로 변경 추적 어려움
- - 가격 히스토리 관리 없음

### 3.3 Phase 3: 자동화 함수 구현

#### 상품코드 자동 생성 수식

```
=CONCATENATE(B2,"-",C2,"-",TEXT(MAXIFS($A:$A,$B:$B,B2,$C:$C,C2)+1,"0000"))
```

#### 사이즈 자동 파싱 수식

```
// 가로 사이즈 추출
=IFERROR(VALUE(TRIM(LEFT(E2,FIND("x",E2)-1))),"")

// 세로 사이즈 추출
=IFERROR(VALUE(TRIM(MID(E2,FIND("x",E2)+1,10))),"")
```

#### 중복 검출 조건부 서식

```
=COUNTIF($D:$D,D2)>1
```

## 4. 전문 에이전트 및 스킬 설계

### 4.1 에이전트 1: 데이터 정규화 에이전트

**역할**: 기존 데이터를 표준화된 형식으로 변환

| 스킬 | 기능 | 구현 방법 |
|------|------|----------|
| 코드 자동생성 | 대분류-중분류-일련번호 조합 | CONCATENATE + MAX |
| 사이즈 파싱 | "105 x 148" 분리 | SPLIT, REGEXEXTRACT |
| 중복 검출 | 동일 상품 식별 | COUNTIF |
| 유효성 검사 | 필수값 누락 체크 | ISBLANK + IF |
| 데이터 변환 | 기존 -> 신규 형식 | VLOOKUP |

### 4.2 에이전트 2: 데이터 유효성 관리 에이전트

**역할**: 데이터 품질 유지 및 입력 지원

| 스킬 | 기능 | 구현 방법 |
|------|------|----------|
| 드롭다운 설정 | 코드 테이블 기반 선택 | 데이터 유효성 검사 |
| 자동 완성 | 상품명 입력 시 코드 매핑 | VLOOKUP/INDEX-MATCH |
| 변경 로그 | 수정 이력 자동 기록 | onEdit Trigger |
| 오류 알림 | 잘못된 값 입력 시 알림 | 조건부 서식 |
| 일괄 검증 | 전체 데이터 품질 검사 | Custom Function |

### 4.3 에이전트 3: 통합 조회 에이전트

**역할**: 전체 상품 데이터 통합 조회 및 리포팅

### B. Apps Script 예시 코드

**상품코드 자동 생성 함수**

```javascript
function generateProductCode(category, subCategory) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet()
      .getSheetByName('PRODUCT_MASTER');
        const data = sheet.getDataRange().getValues();
          
            const prefix = category + '-' + subCategory + '-';
              let maxSeq = 0;
                
                  data.forEach(row => {
                      if (row[0] && row[0].toString().startsWith(prefix)) {
                            const seq = parseInt(row[0].toString().split('-')[2]);
                                  if (seq > maxSeq) maxSeq = seq;
                                      }
                                        });
                                          
                                            return prefix + String(maxSeq + 1).padStart(4, '0');
                                            }
                                            ```
**셀 편집 시 변경 로그 기록**

```javascript
function onEdit(e) {
  const sheet = e.source.getActiveSheet();
    const range = e.range;
      
        if (sheet.getName() !== 'PRODUCT_MASTER') return;
          
            const logSheet = e.source.getSheetByName('CHANGE_LOG');
              if (!logSheet) return;
                
                  const timestamp = new Date();
                    const user = Session.getActiveUser().getEmail();
                      const cell = range.getA1Notation();
                        const oldValue = e.oldValue || '';
                          const newValue = e.value || '';
                            
                              logSheet.appendRow([timestamp, user, sheet.getName(), cell, oldValue, newValue]);
                              }
                              ```
